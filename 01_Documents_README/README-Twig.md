## ⚠️  Syntaxe de Twig

- **{{_}}**     : affiche une expression
- **{%...%}**   : execute une action
- **{#...#}**   : permet d'ajouter des commentaire

## 📋 Les variables Twig

- **{{ objet.attribut}}** : « image.name »  fait référent au nom de l'objet image (image est l'attribut de l'objet) ex: <h1> le nom de l'image est {{ image.toto }} </h1>
